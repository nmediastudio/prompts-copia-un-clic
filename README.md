# Prompts con copia de un clic

Sitio estático en español con cinco prompts organizados y botones para copiar cada prompt o copiarlos todos.

## Desarrollo local

Abre `index.html` directamente en un navegador o sirve esta carpeta con cualquier servidor HTTP estático.

## Despliegue

El proyecto está preparado para importarse y desplegarse en Vercel sin proceso de compilación.
